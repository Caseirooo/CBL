
The user picks ingredients from a catalog and enter quantities to build a pantry that is saved to a file between sessions.
The app then ranks all recipes by how well they match your pantry, shows what’s missing, 
and lets you mark a recipe as finished to subtract the used ingredients.

How to run:
1. File > Open Project, select the CBL folder with pom.xml, and click Open.
2. Right-click the project > Properties > Run > set Main Class to gui.PantryPanel > OK.
3. Press Shift+F11 to build. Wait for BUILD SUCCESS in the Output window.
4. Press F6 to run.

How to run tests:
1. In NetBeans, right-click the project (CBL) in the Projects panel.
2. Click Test.
3. Look at the Test Results window at the bottom. Green means passed, red means failed.
